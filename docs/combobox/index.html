Combobox

Picks one option from a long list by typing to filter.

Combobox primitive
@qinyang/theme@qinyang/icons@qinyang/control-size@qinyang/locale-provider@base-ui/reactclass-variance-authority

Installation

$pnpm dlx shadcn@latest add @qinyang/combobox

Usage

import { Combobox, ComboboxContent, ComboboxEmpty, ComboboxInput, ComboboxItem, ComboboxList } from "@/components/ui/combobox"
<Combobox items={cities}>
  <ComboboxInput placeholder="Search cities" />
  <ComboboxContent>
    <ComboboxEmpty>No city found.</ComboboxEmpty>
    <ComboboxList>
      {(city: string) => (
        <ComboboxItem key={city} value={city}>
          {city}
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>

Composition

Combobox
├── ComboboxInput            (or ComboboxTrigger > ComboboxValue)
└── ComboboxContent
    ├── ComboboxSearch       (with ComboboxTrigger)
    ├── ComboboxEmpty
    └── ComboboxList
        ├── ComboboxItem
        └── ComboboxGroup
            ├── ComboboxLabel
            ├── ComboboxCollection
            │   └── ComboboxItem
            └── ComboboxSeparator

Examples

Search In Popup

Use ComboboxTrigger with ComboboxSearch when the field should look like a select.

Sizes

Set size on Combobox to size the input and its rows together.

Input Options

Turn off controls a field doesn't need, like the clear button when a choice is required.

Controlled

Use value and onValueChange when the selection drives other UI; clearing sets it to null.

Disabled

Disable a ComboboxItem for an unavailable option, or Combobox to lock the field.

RTL

For right-to-left languages, wrap the tree in DirectionProvider and set dir="rtl" on its root.

Keyboard

Typing filters the list; ArrowUp / ArrowDown move the highlight, Enter picks it and Escape closes the popup (standard combobox behaviour).

Related

Multi Select is the same primitive in multiple mode, with chips.

API Reference

Built on the Combobox primitive. Only the props this library adds or changes are listed; everything else passes through.

Combobox

Re-export of the primitive root, taking items, value, defaultValue, onValueChange, filter, disabled and its other props. Also accepts every prop of Combobox.Root.

ComboboxInput

Search input in an inset well with optional search icon, clear and chevron buttons. Also accepts every prop of Combobox.Input.

ComboboxValue

Re-export. Renders the selected value, or placeholder when empty. Also accepts every prop of Combobox.Value.

ComboboxSearch

Search field styled for the top of the popup. Also accepts every prop of Combobox.Input.

ComboboxList

Scrollable list. Takes a render function called per item (or group). Also accepts every prop of Combobox.List.

ComboboxItem

Option row with a check indicator on the right when selected. Also accepts every prop of Combobox.Item.

ComboboxGroup

Also accepts every prop of Combobox.Group.

ComboboxLabel

Also accepts every prop of Combobox.GroupLabel.

ComboboxSeparator

Also accepts every prop of Combobox.Separator.

ComboboxEmpty

Shown only when the filter leaves nothing to pick. Also accepts every prop of Combobox.Empty.

ComboboxCollection

Re-export. Renders a group's items with a render function. Also accepts every prop of Combobox.Collection.

useComboboxFilter

Re-export of Combobox.useFilter, returning locale-aware contains, startsWith and endsWith matchers for filter. Also accepts every prop of Combobox.useFilter.
