Action Swap Blur

A button that blurs its label and icon into the next state.

@qinyang/theme@qinyang/button@qinyang/text-cascademotion
pnpm dlx shadcn@latest add @qinyang/action-swap-blur

Installation

$pnpm dlx shadcn@latest add @qinyang/action-swap-blur

Usage

import { ActionSwapBlurButton } from "@/components/ui/action-swap-blur"
<ActionSwapBlurButton
  resetAfter={1600}
  items={[
    { value: "copy", label: "Copy", icon: <CopyIcon /> },
    { value: "copied", label: "Copied", icon: <CheckIcon /> },
  ]}
/>

Examples

Cycle

Use when one button steps through several states in turn.

Text Only

Use when the states need words but no icon.

Controlled

Use cycle={false} when an async task, like an upload, decides the state.

Custom Slots

Use the slots when the button needs your own layout; a new value triggers the swap.

Animations

Use ActionSwapButton when you pick the animation per button.

Motion

The swap runs 220ms ease-out while the width springs. With reduced motion they cross-fade and the width snaps. Each new state is announced through a polite live region.

Related

Action Swap Roll has the same API with a rolling animation.
